# 📊 Day 01 - Student Data Analysis

## 🎯 Objective

Analyze student performance data using Python and Pandas to understand academic performance and identify factors affecting final grades.

---

## 📂 Dataset

* **Dataset:** Student Performance Dataset
* **Format:** CSV
* **Rows:** 395
* **Columns:** 33

---

## 🛠️ Libraries Used

* Pandas
* NumPy
* Matplotlib
* Seaborn

---

## 🔍 Tasks Performed

* Loaded CSV dataset
* Explored dataset structure
* Checked dataset shape
* Displayed descriptive statistics
* Checked missing values
* Checked duplicate records
* Calculated average final grade
* Counted students scoring above 15
* Calculated correlation between study time and final grade
* Compared average grades by gender

---

## 📈 Visualizations

* Final Grade Distribution (Histogram)
* Study Time vs Final Grade (Scatter Plot)
* Average Grade by Gender (Bar Chart)
