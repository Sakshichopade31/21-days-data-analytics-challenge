# 🌦️ Day 02 - Weather Data Analysis

## 🎯 Objective

Perform exploratory data analysis on a weather dataset to discover weather patterns and visualize important meteorological variables.

---

## 📂 Dataset

* **Dataset:** Weather Dataset
* **Format:** CSV

---

## 🛠️ Libraries Used

* Pandas
* Matplotlib
* Seaborn

---

## 🔍 Tasks Performed

* Loaded weather dataset
* Explored dataset information
* Checked unique weather conditions
* Counted weather occurrences
* Renamed columns
* Calculated mean, variance and standard deviation
* Filtered weather conditions
* Applied grouping and aggregation
* Analyzed snow, fog and clear weather records
* Performed conditional filtering

---

* Wind Speed vs Visibility
* Temperature Distribution
