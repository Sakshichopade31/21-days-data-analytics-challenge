# 📊 Day 04 – Marketing Customer Personality Analysis

## 📌 Project Overview

This project is part of my **21 Days Data Analytics Challenge**.

The objective of this project is to analyze customer personality and purchasing behavior using a real-world marketing campaign dataset. Through Exploratory Data Analysis (EDA), Feature Engineering, Customer Segmentation, and Business Insights, this project identifies valuable customer groups and helps improve marketing strategies.

---

## 🎯 Objectives

* Perform data cleaning and preprocessing.
* Handle missing and duplicate values.
* Create meaningful features for analysis.
* Analyze customer demographics and purchasing behavior.
* Identify high-value customers.
* Evaluate marketing campaign performance.
* Generate business insights through data visualization.

---

## 🛠️ Tech Stack

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📂 Dataset

**Dataset:** Marketing Campaign Dataset

The dataset contains customer demographic information, purchasing history, product spending, campaign responses, and website interactions.

---

## 📋 Project Workflow

### 1. Data Loading

* Import dataset
* Explore dataset structure
* Check shape and column information

### 2. Data Cleaning

* Handle missing values
* Remove duplicate records
* Convert data types
* Drop unnecessary columns

### 3. Feature Engineering

Created new features such as:

* Age
* Total Children
* Total Spending
* Customer Tenure
* Income Category
* Age Group
* Parent Category

### 4. Exploratory Data Analysis (EDA)

Performed:

* Univariate Analysis
* Bivariate Analysis
* Product Analysis
* Marketing Campaign Analysis
* Correlation Analysis

### 5. Customer Segmentation

Identified:

* High Value Customers
* Low Value Customers
* Premium Customers
* Loyal Customers
* Inactive Customers
* Discount Lovers

### 6. Business Insights

Generated actionable insights for improving marketing strategies and customer engagement.

---

## 📊 Key Insights

* High-income customers tend to spend significantly more.
* Wine products generated the highest overall revenue.
* Adult customers formed the largest customer segment.
* Loyal customers had lower recency values.
* Customers responding to discounts showed higher deal purchases.
* Customer segmentation enables personalized marketing campaigns.
* Marketing campaigns have room for improving customer response rates.
